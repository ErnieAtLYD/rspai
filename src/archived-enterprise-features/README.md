# Archived Enterprise Features

This folder contains the sophisticated enterprise-level features that were developed for RetrospectAI but are not needed for the MVP release.

## Why These Files Are Archived

These files represent approximately 80% complete enterprise-grade functionality that was built during the initial development phase. While they are well-architected and tested, they were deemed too complex for the initial MVP release.

## What's Archived Here

### Core Enterprise Architecture
- `pattern-detection-engine.ts` - Advanced pattern detection (53KB, 80% complete)
- `ai-service-orchestrator.ts` - Multi-stage AI orchestration
- `unified-ai-interfaces.ts` - Unified interface system
- `unified-ai-data-structures.ts` - Advanced data structures
- `unified-error-handling.ts` - Enterprise error handling
- `unified-model-manager.ts` - Advanced model management

### Advanced AI Features
- `ollama-adapter.ts` - Local Ollama integration
- `llamacpp-adapter.ts` - Llama.cpp integration  
- `mock-ai-adapter.ts` - Testing adapter
- `ai-translation-layer.ts` - Translation utilities
- `ai-retry-recovery-manager.ts` - Retry logic
- `extensible-ai-factory.ts` - Plugin architecture

### Advanced Processing Systems
- `summary-note-creator.ts` - Advanced summary generation
- `summary-template-engine.ts` - Template system
- `natural-language-generator.ts` - NLG system
- `nlp-processor.ts` - NLP processing
- Pattern detection and theme analysis files
- Recommendation and insight generation engines

### Utilities & Tools
- Advanced markdown processing
- Performance optimization
- Resilience management
- Scanning utilities
- Plugin registry system

### Backup Files
- `main-simplified.ts` - Source template for current main.ts
- `main-ultra-simple.ts` - Ultra-minimal version
- `example-enhanced-openai-plugin.ts` - Example file

## Future Plans

These features will be gradually reintroduced in post-MVP releases based on:
- User feedback and demand
- Real-world usage patterns  
- Performance requirements
- Community contributions
